This POC demonstrates **Playwright UI automation with a dynamic QA dashboard**.

### Flow

```text
Playwright Tests
      ↓
GitHub Actions
      ↓
Test Results + HTML Report
      ↓
Dynamic QA Dashboard
      ↓
GitHub Pages
```

### What it includes

* Playwright UI automation
* Page Object Model (POM)
* Helpers and JSON test data
* GitHub Actions CI execution
* Dynamic test module/status reporting
* Centralized Playwright HTML report
* GitHub Pages dashboard

### Dashboard

The dashboard automatically displays the modules and test results from the Playwright execution.
